# Getting help

Pick the shortest path for what you need.

| I want to... | Go here |
| --- | --- |
| Understand the network | [inazuma-docs](https://github.com/inazuma-network/inazuma-docs) |
| Run a validator or a node | [validator guide](https://github.com/inazuma-network/inazuma-docs/blob/main/docs/validator.md) |
| Build an app | [inazuma-sdk](https://github.com/inazuma-network/inazuma-sdk) |
| Use a wallet | [inazuma-wallet](https://github.com/inazuma-network/inazuma-wallet) |
| Get test INAZ | [faucet guide](https://github.com/inazuma-network/inazuma-docs/blob/main/docs/faucet.md) |
| Report a bug | Open an issue in the repository the bug is in |
| Report a vulnerability | Email security@inazuma.network — never a public issue |
| Propose a protocol change | [inazuma-improvement-proposals](https://github.com/inazuma-network/inazuma-improvement-proposals) |

## Before you open an issue

Please include the version or commit, the exact command you ran, the full error
text (not a screenshot of it), and your operating system. Questions with those four
things get answered in one round instead of five.

## Response times

This is maintained by a small team. Bug reports usually get a first reply within a
few days. Security reports get one within 48 hours.
